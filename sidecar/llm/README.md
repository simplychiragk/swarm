# Swarm LLM Gateway (`sidecar/llm`)

Multi-provider LLM abstraction layer providing unified completions, priority fallback chaining, request retries, provider cooldowns, and structured JSON output.

---

## Purpose
- Provide a single, reliable async entry point for all Swarm agents (Queen, Workers, Scribe).
- Fallback seamlessly: **NVIDIA NIM** -> **OpenRouter free models** -> **Bring-Your-Own-Key (BYOK)**.
- Guarantee offline capability via deterministic mock completion when `SWARM_LLM_MODE=mock` or when keys are absent.

---

## Public Interface

```python
from sidecar.llm import complete, LLMResult

async def complete(
    messages: List[Dict[str, str]],
    *,
    tier: str = "fast",
    json_schema: Optional[Union[Dict[str, Any], Type[BaseModel]]] = None,
    timeout: float = 30.0,
) -> LLMResult:
    """Dispatches a chat completion across the fallback chain."""
```

### `LLMResult` Attributes
- `text`: Raw text generated by model.
- `parsed`: Validated object if `json_schema` was provided (Pydantic model or dict); else `None`.
- `provider`: Provider that fulfilled request (`"nvidia"`, `"openrouter"`, `"byok"`, or `"mock"`).
- `model`: Exact model identifier used.
- `latency_ms`: Execution time in milliseconds.

## Usage Example

### Plain Text Completion
```python
import asyncio
from sidecar.llm import complete

async def run():
    result = await complete(
        messages=[
            {"role": "system", "content": "You are a backend worker."},
            {"role": "user", "content": "Design the waitlist API route shape."},
        ],
        tier="fast",
    )
    print(f"[{result.provider}] {result.text}")

asyncio.run(run())
```

### Structured Output with Pydantic
```python
from pydantic import BaseModel
from sidecar.llm import complete

class TaskPlan(BaseModel):
    tasks: list[dict]

async def plan():
    result = await complete(
        messages=[{"role": "user", "content": "Break down waitlist landing page"}],
        tier="smart",
        json_schema=TaskPlan,
    )
    # result.parsed is guaranteed to be a valid TaskPlan instance
    for task in result.parsed.tasks:
        print(task)
```

## Configuration & Environment Variables

| Variable | Description |
|---|---|
| `SWARM_LLM_MODE` | Set to `"mock"` (default) for deterministic offline testing, or `"live"` for real API calls. |
| `NVIDIA_NIM_API_KEY` | Key for NVIDIA NIM API (`https://integrate.api.nvidia.com/v1`). |
| `OPENROUTER_API_KEY` | Key for OpenRouter (`https://openrouter.ai/api/v1`). |
| `BYOK_API_KEY` | Optional third-tier key. |
| `BYOK_BASE_URL` | Optional base URL for BYOK (defaults to `https://api.openai.com/v1`). |

---

## Resiliency & Known Limits

- **Rate Limits (429):** Retries up to 2 times with a 1.5s backoff before falling through to the next provider.
- **Failures & Cooldowns:** Consecutive failures (>=3) place the failing provider into a 60-second cooldown window so subsequent agent turns don't stall.
- **JSON Repair:** If a model returns malformed JSON, a repair prompt is automatically dispatched once.
- **Limits:** Max single request timeout is configurable per call (default: 30s).
